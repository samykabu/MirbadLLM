# Diagram sources

Each `.html` file here is the source of the SVG with the same name in `docs/images/`. The diagrams follow the
Illustrate skill's editorial style in the MirbadLLM theme (`.github/illustration-theme.yml`: the graphite and amber
of the website, Inter, Plus Jakarta Sans and Azeret Mono).

To change a diagram:

1. Edit its `.html` file (`host-services.html` is generated by `gen_host_services.py <any themed page> host-services.html`).
2. Export the SVG with the Illustrate skill: `python scripts/export_diagram.py <file>.html --svg-only --output <name>`.
3. Embed the fonts, so the SVG renders in the brand fonts inside an `<img>` (which never loads remote fonts):
   `python embed_fonts.py <mirbadllm-site>/node_modules <name>.svg docs/images/<name>.svg`. It needs `fonttools` and
   `brotli`, and subsets each font to the diagram's own text, so a diagram stays around 30 to 50 KB.
